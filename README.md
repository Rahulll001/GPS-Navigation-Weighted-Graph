
# GPS Navigation Using Weighted Graph

## Introduction
This project represents a city map using a weighted
graph. Locations are vertices and roads are edges.

## Objective
To find the shortest path between two locations.

## Data Structure
Weighted Graph using an Adjacency List.

## Algorithm
Dijkstra's Shortest Path Algorithm.

## Features
- Represents city locations and roads.
- Stores road distances as weights.
- Finds the shortest path.
- Displays the total distance.

## Output
Starting Point: A
Destination: E
Shortest Path: A -> C -> B -> D -> E
Total Distance: 10 km

## Time Complexity
O((V + E) log V) using an adjacency list
and a priority queue.

## Conclusion
Dijkstra's algorithm finds the shortest route
in a weighted graph with non-negative distances.
